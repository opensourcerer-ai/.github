# Roger Allan

Roger Allan is a software engineer working on AI-assisted software development, software reliability, security, cryptography, and long-lived software systems.

This page is a public index of projects, publications, videos, and other professional work. It is intended to make the underlying work easy to find and inspect.

## Projects

### SCA — Security Control Agent

AI-assisted repository security analysis using explicit security constraints to guide reasoning and produce evidence-based findings.

Repository: [github.com/opensourcerer-ai/sca](https://github.com/opensourcerer-ai/sca)

### FMA — Failure Mode Agent

AI-assisted repository analysis focused on software failure modes, operational weaknesses, unsafe recovery behavior, and implementation patterns that can lead to instability.
